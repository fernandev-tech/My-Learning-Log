
🧠 Então guarda esta sequência
Se amanhã alguém te entregar qualquer projeto, tenta pensar:

# 1. Qual problema estamos resolvendo?

# 2. Quem usa o sistema?

# 3. O que cada usuário precisa conseguir fazer?

# 4. Quais funcionalidades precisamos?

# 5. Quais regras precisam ser respeitadas?

# 6. Como os usuários percorrem o sistema?

# 7. Quais dados existem e como se relacionam?

# 8. Como as partes do sistema se comunicam?

# 9. Qual tecnologia vamos utilizar?

# 10. Como organizaremos o projeto?

# 11. Como será a interface?

# 12. Agora sim: código.
